# 交互阅读（dsh-interactive-reader）

把一场对话变成可以安静阅读的页面：过程实时折叠、可跳轮次、差异可展开、产物可定位，最终回答里还能挂 MCP Apps 交互卡片。左侧栏「阅读」入口，或任意会话内切换到阅读页。

## 设置项说明

以下设置都在 **设置 → 交互阅读** 中（本详情页只作说明，修改请到设置页）。

### 在内置面板中打开产物

默认**关闭**。关闭时，回答里出现的文件芯片和正文中的文件提及会用系统应用打开；打开后与官方对话一致，在右侧栏预览。「在文件夹中显示」与「打开所在文件夹」不受此开关控制，始终走系统文件管理器。

### 半透明毛玻璃

默认**关闭**。打开后阅读页透出宿主壁纸与皮肤；路径、行数等标签静止时透明，悬停或聚焦才显出轮廓。

### 自动折叠过程

默认**开启**：新的思考产生时，自动折叠此前的推理和工具调用，旁白正文永远保持展开。块与块之间会出现一条紧凑的过程摘要（如 `思考×2 · 工具×1`），点击可原地展开被折叠的行。关闭后全程展开，完整保留原始思考与工具流。

### fnOS 文件管理器地址

只在宿主**没有桌面**（如 fnOS / NAS）时显示，Windows / macOS 宿主上这一项自动隐藏。填上之后，「在文件夹中显示」会改为打开 NAS 的文件管理器，而不是悄无声息地什么都没发生。

- 必须包含路径占位符，且只对 `/vol{n}/…` 路径生效。
- 占位符：`{path}` 原始路径、`{encodedPath}` URL 编码路径、`{name}` 目录名。
- 示例：`http://<nas>:5666/v/trim.file-manager?path={encodedPath}`

### generative-mcpapps 技能

这项检测只影响**模型自动选用 MCP Apps**；阅读页在模型写出 mcp-app 代码块时本来就会渲染，不依赖该技能是否装进宿主。点「重新检测」查询宿主技能目录；未检测到时页面会给出安装命令（把 `generative-mcpapps` 文件夹复制到 `.dsh/skills` 或 `.agents/skills`，家目录或项目目录均可）。

## 与其他插件协作

- **dsh-rewind-plugin**：`/rewind` 成功后，阅读页会把被撤回的消息、其后的行和命令行本身一起收起，回退到发送前的状态。
- **文本变换服务**（`dsh-interactive-reader.text-transform`）：其他插件可注册变换器，在阅读呈现前改写推理和回答文字；会话记录保持原文。
- **第三方渲染器**：注册在官方节点插槽上的 user/steering/assistant-step 渲染器（如消息召回按钮、原始 HTML 卡片）会在阅读页内继续生效。

## 安装

```
dsh plugin --profile web add github:huiikeung/dsh-interactive-reader
```

设置页与详情页的全部文案随界面语言切换（中文 / English）。
